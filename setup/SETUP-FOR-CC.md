# brain-tap セットアップ手順書

このファイルは、Googleログインと点数のクラウド保存の初期設定手順書です。

AI はこのファイルを見ながら次の順で進行する。
ユーザーは AI の案内に従えばよい。
一度に全部見せず、次の1アクションだけを伝える。
**案内するときは、操作に加えて「なぜそうするか」を短く添える。**

## 前提

## 前提

- 接続情報は `js/firebase-config.js` に置く（ユーザーにはファイルを編集させない）
- Firebase の画面上のキーは、このアプリでは公開して使うのが正式な使い方（誰でも読めるが、点数は本人だけが読み書きできる）

## AI が最初に確認すること

1. `js/firebase-config.js` に `apiKey` と `projectId` が入っていること
2. ユーザーが Google でログインできること
3. 点数がクラウドに残ること

全て揃っていれば「セットアップ済みです」と伝えてスキップ。
不足があるものだけ、以下の該当ステップを実行する。

## 進行フロー

### ステップA: Firebase のプロジェクトを作る

Googleログインと点数保存のための箱を作る。アプリ本体とは別の、Google側の置き場。

途中で出る余分なものはオフにする。理由: 今回必要なのはログインと点数だけ。足すと画面が増え、後から分かりにくくなる。あとからオンにもできる。

```text
Googleログイン用の箱を作ります。
（ログインと点数を置く場所が必要なので、先に箱を作ります）

1. https://console.firebase.google.com/ を開く
2. 「プロジェクトを追加」をクリック
3. プロジェクト名は「brain-tap」でOK
4. 「Firebase の規約に同意します」にチェック（続行を押すために必要）
5. 「Firebase で Gemini を有効にする」はオフ
   （GeminiはFirebaseのAI補助。今回のログインには使わない。オンにすると入力が学習に使われる案内もある）
6. Google アナリティクスは「無効」
   （訪問者の動きを集める機能。今は不要）
7. 「プロジェクトを作成」をクリックし、終わるまで待つ

できたら「できた」と教えてください。
```

### ステップB: ウェブアプリを登録する

```text
次に、このツールを Firebase に登録します。

1. プロジェクトのトップで「ウェブ」のアイコン（</>）をクリック
2. アプリのニックネームは「brain-tap」でOK
3. 「Firebase Hosting も設定する」は、今はチェックしない
   （Hostingは別の公開方法。今はGitHub Pagesで公開しているので二重になる）
4. 「アプリを登録」をクリック
5. 出てきた firebaseConfig の中身（apiKey など）を、このチャットに貼る

貼ってもらえたら、こちらでファイルに書きます。
```

### ステップC: Google ログインを有効にする

```text
次に、Google でログインできるようにします。

1. 左メニュー「Authentication」（ビル）をクリック
2. 「始める」があればクリック
3. 「Sign-in method」→「Google」→「有効にする」
4. プロジェクトのサポートメールを選んで「保存」

できたら「できた」と教えてください。
```

### ステップD: 点数の保存場所（Firestore）を作る

```text
次に、点数を置く場所を作ります。

1. 左メニュー「Firestore Database」をクリック
2. 「データベースの作成」をクリック
3. 「本番環境モード」を選ぶ
   （テスト用だと誰でも点数を触れる可能性がある。最初から本人だけに制限する）
4. 場所は「asia-northeast1（東京）」を選んで作成
   （日本から使うので、近い場所のほうが速い）

できたら「できた」と教えてください。
```

### ステップE: 誰が点数を読めるかのルールを入れる

AI が `firestore.rules` の内容を案内し、ユーザーに貼ってもらう。

```text
点数は、本人だけが読めるようにします。

1. Firestore の「ルール」タブを開く
2. 中身を、チャットに出すテキストで全部置き換える
3. 「公開」をクリック

できたら「できた」と教えてください。
```

### ステップF: ログインしてよいサイトを許可する

公開ページ（GitHub Pages）からもログインできるようにする。
`localhost` は最初から入っていることが多い（自分のパソコン用）。

足す住所: `ponnmayo15-a11y.github.io`
（`https://` は付けない）

```text
次に、公開ページからログインできるようにします。
（許可した住所からしか、Googleログインできないためです）

1. 設定 → プロジェクトの設定 → 全般 → 下へスクロール →「承認済みドメイン」
   または https://console.firebase.google.com/project/brain-tap-3cbf0/authentication/settings
2. 「ドメインを追加」をクリック
3. ponnmayo15-a11y.github.io と入力（https:// は付けない）
4. 追加をクリック

できたら「できた」と教えてください。
```

## 完了の定義

- `js/firebase-config.js` に値が入っている
- Google ログインが有効
- Firestore が東京リージョンで作成済み
- ルールが本人のみ読み書き
- `http://localhost:5175` で Google ログインでき、点数が残る
- 公開ページ `https://ponnmayo15-a11y.github.io/brain-tap/` でもログインできる
- 承認済みドメインに `ponnmayo15-a11y.github.io` が入っている

## よくあるつまずき

- ポップアップがブロックされた → ブラウザの許可を出す。スマホは画面が一度切り替わる
- 「unauthorized domain」→ 承認済みドメインに `ponnmayo15-a11y.github.io` を足す。`https://` や `/brain-tap/` は付けない
- 公開ページでポップアップが失敗する → 画面遷移ログインを使う（実装済み）
- 点数はログインできたのに残らない → ルールの公開ができていない
