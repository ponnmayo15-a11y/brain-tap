# brain-tap の調整

brain-tap の画面や課題を、ユーザーの「こうしたい」に合わせて直す。

## 使う場面

- ユーザーが「難しくして」「ボタンを大きくして」「記録の見方を変えて」と言ったとき

## 実行手順

1. いまの範囲を確認する（CLAUDE.md のやること / やらないこと）
2. 1つの変更だけ入れる
3. `npm start` で画面が開くことを確認する
4. 何を変えたかを平易な日本語で伝える

## 基本姿勢

- 最初は最小限。複雑になりそうなら「シンプルにするとこうなります」と代替案を出す
- タッチが本体。小さなボタンやキーボード入力に戻さない
- 医療の効果は言わない
- 操作を案内するときは「なぜそうするか」を短く添える
- 関数は短く、冒頭に日本語コメントを書く
